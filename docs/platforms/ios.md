# iOS

`KotlinResult` reaches iOS only through the Apple framework of the KMP library
that exports it — there is no standalone XCFramework or Swift package. No entitlements or
`Info.plist` keys are needed. See [Use it from a KMP library](../recipes/kmp-library.md)
for the required `export`, and [Getting started](../getting-started.md) for the
Swift API.
